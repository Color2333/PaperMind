2.0 改了什么

不是加功能——是把地基整个换掉：执行、智能、终端三层全部重构。

🏛️

Go 权威执行面

Job / Task / Attempt 与领域写入收敛到 Go 单事务。fencing 令牌防脑裂、崩溃可恢复、死信可追溯——任务系统从"尽力而为"变成"必达且可审计"。

🧠

Pi Agent 单网关

所有 LLM 调用统一经 Pi 网关（pi-ai 底座）。provider 换型零改码、配置热生效。Agent 循环同时驱动网页聊天与终端。

🖥️

云端 CLI 终端

pm 三形态：全屏 TUI · 一次性问答 · 确定性命令面。零本地依赖——登录即用，换机器续接同一会话。

⚡

双执行池 + 闲时补偿

compute / orchestration 双池隔离长短任务；闲时自动补偿精读，在途去重、PDF 不可用自动标记——不重复计费，不无限重试。

🛡️

持久化且可审计

每次 LLM 调用有 token 与成本记录，每个任务有 Attempt 历史。2.0 的信条：执行过的必须留下证据。

🔄

与 Web 同源

终端里的会话与网页聊天共享同一存储——CLI 里聊到一半，打开网页接着聊。你的研究上下文不再被客户端割裂。
